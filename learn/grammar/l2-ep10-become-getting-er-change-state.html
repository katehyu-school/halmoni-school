-아/어지다To become / Getting ___-er (change of state)

Level 2핵심 문법🩺 건강·몸상태 · Health & Motion
Adj stem (ㅏ/ㅗ) + -아지다 · Adj stem (other) + -어지다 · ㅎ-irregular: ㅎ drops → -아/어지다

Attach -아/어지다 to an adjective to describe a gradual change or shift in state. Think of it as 'it got ___' or 'it became ___'.

이야기 속에서는 이렇게 쓰입니다

속이 좀 괜찮아졌어? / 이제 좀 나아진 것 같아.
Is your stomach any better? / I think I'm starting to feel better now.

규칙

Change of state · 상태 변화Adjective + 아/어지다 = 'it got ___' / 'it became ___'
좋다 → 좋아지다 (get better)
나쁘다 → 나빠지다 (get worse)
따뜻하다 → 따뜻해지다 (become warm)
Past tense form · 과거형-아/어졌어요 = it got ___ (past)
괜찮아졌어요 — she's feeling better now
날씨가 따뜻해졌어요 — the weather has warmed up
ㅎ irregular · ㅎ 불규칙ㅎ adjectives drop ㅎ before 아/어:
좋다 → 좋아지다 ✓ (ㅎ없음 — regular)
빨갛다 → 빨개지다 (ㅎ drops)
하얗다 → 하얘지다 (ㅎ drops)

예문

건강·몸 상태

  • 많이 나아졌어요.I'm feeling much better.
  • 목이 아파졌어요.My throat started hurting.

날씨·환경

  • 날씨가 추워졌어요.It's gotten cold out.
  • 방이 깨끗해졌어요.The room has gotten clean.
