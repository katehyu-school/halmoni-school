-아/어 보다Try doing something

Level 2핵심 문법🚌 교통·길찾기 · Getting Around
Verb stem + 아/어 보다 (same vowel rule as 아요/어요)

-아/어 보다 means 'to try doing' something or doing it to see how it goes. It adds a sense of experience or attempt — 'give it a go'.

이야기 속에서는 이렇게 쓰입니다

찾아 봐. / 해 볼게요.
Try looking for it. / I'll give it a try.

규칙

Try doing → -아/어 봐(요) / 보세요먹어 봐! Try eating it!
해 보세요. Please give it a try.
가 봐. Go and see.
Past: already tried → -아/어 봤어(요)먹어 봤어요. I tried eating it.
해 봤어. I tried doing it.

형태별 정리

형태쓰임예
ㅏ/ㅗ 어간찾아 보다, 봐요
그 외 어간먹어 보다, 해 보다

예문

  • 이 음식 먹어 봐!Try eating this food!
  • 한번 해 볼게요.I'll try it once.
  • 찾아 보세요.Please try looking.
💡 팁Try something new · 새로운 것을 시도할 때 써요. -아/어 보다 = give it a go!
