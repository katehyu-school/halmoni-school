-(으)시- 높임법The Honorific Marker -(으)시-

Level 2핵심 문법🛒 쇼핑·가입 · Shopping & Membership
Verb stem + -(으)시 + ending · Vowel/ㄹ stem + -시 · Consonant stem + -으시

Insert -(으)시- between the verb stem and its ending to show respect for whoever is doing the action. Think of it as a 'respect switch' built inside the verb. If the subject is a customer, elder, or someone you're being polite to — flip the switch.

이야기 속에서는 이렇게 쓰입니다

회원가입을 하시면 훨씬 더 할인돼요.
If YOU sign up for membership, you'll get a much bigger discount.

규칙

가다 → 가세요 · 오다 → 오세요 · 하다 → 하세요
가입하다 → 가입하시면 · 이용하다 → 이용하세요
있다 → 있으세요 · 읽다 → 읽으세요 · 찾다 → 찾으세요
회원권 있으세요? = Do you have a membership card?
주다 → 드리다 (give)
먹다/마시다 → 드시다 (eat/drink)
있다 → 계시다 (be, exist)
말하다 → 말씀하시다 (say)
묻다 → 여쭙다 (ask)
❌ 할인 되세요 · ❌ 주문이 나오셨어요
✅ 할인돼요 · ✅ 주문이 나왔어요
사람이 아닌 것(할인, 주문)에는 -(으)시-를 쓰지 않아요.
You can't show respect to a discount or an order — only to people!
(한국 서비스업에서 매우 많이 들리지만 문법적으로는 틀렸어요.)

예문

Verb + -(으)시 + ending

  • 앉으세요.Please sit down.
  • 기다리세요.Please wait.
  • 보여 주시고…Please show (and)…
  • 이용하셔야 돼요.You'll need to use (it).

Special honorific vocabulary

  • 계산해 드릴까요?Shall I ring that up for you? (드리다 = honorific 주다)
  • 선생님이 계세요?Is the teacher in? (계시다 = honorific 있다)
  • 뭐라고 말씀하셨어요?What did you say? (말씀하시다 = honorific 말하다)
