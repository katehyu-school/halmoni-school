-(으)ㄴ 것 같아요It seems like ~ / I think ~ (observation/inference)

Level 2핵심 문법🩺 건강·증상 · Health & Symptoms
Past verb / Adjective + -(으)ㄴ 것 같아요

-(으)ㄴ 것 같아요 means 'it seems like' or 'it looks like' — a judgment based on what you can observe RIGHT NOW. Use it with past-tense verbs (걸린, 먹은) or adjectives (아픈, 피곤한).

이야기 속에서는 이렇게 쓰입니다

아까 개울에서 놀아서 감기 걸린 것 같아.
It seems you caught a cold from playing in the stream earlier.

규칙

Past action → verb + -(으)ㄴ 것 같아요걸리다 → 걸린 것 같아요 (seems like caught a cold)
먹다 → 먹은 것 같아요 (seems like ate already)
Current state (adjective) → adj + -(으)ㄴ 것 같아요아프다 → 아픈 것 같아요 (seems sick)
피곤하다 → 피곤한 것 같아요 (seems tired)
💡 Compare with ep04 — -(으)ㄹ 것 같아요-(으)ㄴ 것 같아요 = seems like [now/past]
-(으)ㄹ 것 같아요 = looks like [will happen]

형태별 정리

형태쓰임예
동사 과거: -(으)ㄴ 것 같아요이미 일어난 일 추측감기에 걸린 것 같아요 (Seems like I caught a cold)
동사 현재: -는 것 같아요지금 일어나는 일 추측열이 나는 것 같아요 (Seems like I have a fever)
형용사: -(으)ㄴ 것 같아요현재 상태 추측·판단열이 없는 것 같아요 (Seems like there's no fever)

예문

past verb + -(으)ㄴ 것 같아요

  • 감기에 걸린 것 같아요.Seems like I caught a cold.
  • 밥을 먹은 것 같아요.Looks like he already ate.

adjective + -(으)ㄴ 것 같아요

  • 많이 아픈 것 같아요.She seems really sick.
  • 날씨가 추운 것 같아요.The weather seems cold.
  • 감기에 걸린 것 같아요.It seems like I caught a cold.
  • 열이 없는 것 같은데, 병원에 가 볼까?It seems there's no fever, but shall we go to the hospital?
  • 열이 펄펄 나는 것 같아요.It seems like I have a high fever.
  • 피곤한 것 같아.It seems like (you're) tired.
💡 팁보이는 것·느끼는 것을 부드럽게 표현할 때 써요 · Use when making gentle observations or inferences based on what you see/feel — instead of stating facts directly.
⚠️ -(으)ㄹ 것 같아요 (미래 예측: 비가 올 것 같아요)는 다음 레벨에서! · -(으)ㄹ 것 같아요 for future prediction comes in Level 3!
