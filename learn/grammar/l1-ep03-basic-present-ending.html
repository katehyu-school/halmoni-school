-아요 / -어요 — 동사·형용사 기본 활용-아요/-어요 — The Basic Present Ending

Level 1핵심 문법🍽️ 식사예절 · Table Manners

어간(stem) 마지막 모음이 ㅏ/ㅗ → -아요 | 그 외 → -어요 | 하다 → 해요

Almost every Korean verb and adjective ends in -아요 or -어요 in polite speech. The vowel in the LAST syllable of the stem decides which one. This is THE most important pattern in Korean.

이야기 속에서는 이렇게 쓰입니다

엄마, 이거 너무 맛있어요!
Mom, this is so delicious!

규칙

Stem vowel is ㅏ or ㅗ → 아요가다 → 가요 · 좋다 → 좋아요 · 알다 → 알아요
Other vowels → 어요먹다 → 먹어요 · 마시다 → 마셔요 · 있다 → 있어요
하다 → 해요 ⭐ (always!)공부하다 → 공부해요 · 운동하다 → 운동해요
All -하다 verbs follow this rule!
사전형 Dictionary어간 Stem마지막 모음활용형 Polite

예문

ㅏ / ㅗ → 아요

  • 가다 → 가요to go → goes / going
  • 좋다 → 좋아요to be good → it's good
  • 알다 → 알아요to know → knows

other vowels → 어요

  • 먹다 → 먹어요to eat → eats / eating
  • 마시다 → 마셔요to drink → drinks
  • 맛있다 → 맛있어요to be delicious → it's delicious

하다 → 해요 ⭐

  • 공부하다 → 공부해요to study → studies
  • 운동하다 → 운동해요to exercise → exercises
  • 배구하다 → 배구해요to play volleyball → plays volleyball
  • 맛있어요!It's delicious! (맛있다 → 맛있어요)
  • 저는 밥을 먹어요.I eat rice/a meal. (먹다 → 먹어요)
  • 배구를 해요.I play volleyball (하다 → 해요)
