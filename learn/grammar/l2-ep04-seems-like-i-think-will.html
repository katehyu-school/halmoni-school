-(으)ㄹ 것 같아Seems like / I think it will ~

Level 2핵심 문법🌤️ 날씨·여가 · Weather & Leisure
Verb/adj stem + -ㄹ 것 같아요 (vowel/ㄹ) / -을 것 같아요 (consonant)

-(으)ㄹ 것 같아요 expresses a PREDICTION or GUESS about what will happen — based on how things look right now. You're not certain, but it seems likely.

이야기 속에서는 이렇게 쓰입니다

비가 올 것 같아.
Looks like it's going to rain.

규칙

Vowel or ㄹ stem → -ㄹ 것 같아요오다 → 올 것 같아요 · 알다 → 알 것 같아요 · 날다 → 날 것 같아요
Consonant stem → -을 것 같아요먹다 → 먹을 것 같아요 · 좋다 → 좋을 것 같아요
💡 Compare with ep03 — -(으)ㄴ 것 같아요비가 올 것 같아요. Looks like it will rain. (future)
비가 온 것 같아요. Looks like it rained. (past)

형태별 정리

형태쓰임예
-ㄹ 것 같아모음/ㄹ 받침 어간오다 → 올 것 같아, 알다 → 알 것 같아
-을 것 같아자음 받침 어간 (ㄹ 제외)먹다 → 먹을 것 같아, 좋다 → 좋을 것 같아

예문

vowel / ㄹ stem → -ㄹ 것 같아요

  • 비가 올 것 같아.Looks like it's going to rain.
  • 나는 눈물이 날 것 같아.I feel like I'm going to cry.
  • 이거 맛있을 것 같아요!This looks like it'll be delicious!

consonant stem → -을 것 같아요

  • 오늘 늦을 것 같아요.I think I'll be late today.
  • 많이 좋을 것 같아요.I think it'll be really good.
  • 비가 올 것 같아.Looks like it's going to rain.
  • 나는 눈물이 날 것 같아.I feel like I'm going to cry.
  • 오늘 늦을 것 같아요.I think I'm going to be late today.
  • 이거 맛있을 것 같아!This looks like it'll be delicious!
💡 팁추측이나 예측을 말할 때 써요. 영어의 'looks like / I think it will ~'과 비슷해요. · Use for guesses or predictions — based on what you see or feel!
