-을 / -를 목적격 조사Object Particle -을 / -를

Level 1핵심 문법🍽️ 식사예절 · Table Manners
명사(받침 O) + 을 | 명사(받침 X) + 를

명사(받침 O) + 을 | 명사(받침 X) + 를

The object particle marks WHAT the action is done to. Use 을 after a consonant-ending noun, 를 after a vowel-ending noun. The object particle is often dropped in casual speech.

규칙

받침 없으면 → 를 · Vowel ending → 를배구를, 한국어를, 뭘 (= 무엇을)
받침 있으면 → 을 · Consonant ending → 을밥을, 김밥을, 책을
단어 Word받침 Final?조사 Particle예문 Example
밥O (ㅂ)을밥을 먹어요
배구X (ㅜ)를배구를 해요
공O (ㅇ)을공을 받아!
우리X (ㅣ)를우리를 불러요

예문

  • 저는 배구를 해요.I play volleyball.
  • 밥을 먹어요.I eat rice.
  • 내 공 받아!Catch my ball!
  • 엄마가 우리를 불러요.Mom calls us.
  • 배구를 해요. = 배구하다Play volleyball — 하다 verbs can merge: 배구를 하다 ↔ 배구하다
💡 팁💡 하다 동사: '배구를 하다' → '배구하다'처럼 활동+를+하다는 붙여 쓸 수 있어요! · Activity + 를 + 하다 can merge into one word.
