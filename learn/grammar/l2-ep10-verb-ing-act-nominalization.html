-는 것 (명사화)Verb-ing / The act of ___ (nominalization)

Level 2핵심 문법🩺 건강·몸상태 · Health & Motion
Verb stem + -는 것 (present) · Verb stem + -(으)ㄴ 것 (past/completed)

Turn any verb into a noun by adding -는 것. This is one of the most powerful structures in Korean — it lets you use whole verbs as subjects, objects, or complements.

이야기 속에서는 이렇게 쓰입니다

참는 게 힘들어요. / 멀미를 참는 것이 쉽지 않지. / 나아진 것 같아.
Holding on is so hard. / Fighting off motion sickness isn't easy. / It seems like I've gotten better.

규칙

Verb → Noun · 동사를 명사로Verb + -는 것 = 'the act of ___-ing'
참다 → 참는 것 (holding on / the act of enduring)
먹다 → 먹는 것 (eating / food)
배우다 → 배우는 것 (learning)
Shorthand forms · 줄임말-는 것이 → -는 게 (subject)
-는 것을 → -는 걸 (object)

참는 것이 힘들어요 = 참는 게 힘들어요
좋아하는 것을 해요 = 좋아하는 걸 해요
Past state: -(으)ㄴ 것 같다For completed actions or past states, use -(으)ㄴ 것:
나아지다 → 나아진 것 같아 = it seems like (I've) gotten better
먹다 → 먹은 것 같아 = it seems like (someone) ate it

Present: 자는 것 같아 (seems to be sleeping)
Past: 잔 것 같아 (seems to have slept)

예문

  • 운동하는 것이 중요해요.Exercising is important.
  • 한국어를 배우는 게 재미있어요.Learning Korean is fun.
  • 이미 끝난 것 같아요.It seems like it's already over.
